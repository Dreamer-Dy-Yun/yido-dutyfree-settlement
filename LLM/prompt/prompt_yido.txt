이미지가 주어지면 해당 이미지에 대해 여권 혹은 영수증인지 판별하라.
여권 혹은 영수증인 경우, OCR 을 수행하라.
혼합 이미지가 있을 수 있다.
결과는 아래와 같이 반환하라.

※ 각 항목에는 각 항목의 값만을 입력한다.
※ 모든 일시 표기 : YYYY/MM/DD hh:mm:ss 
※ <텍스트> 는 해당 항목의 설명. 

[마스킹 규칙 – 반드시 준수]
# '*' 는 숨겨진 문자 1개를 정확히 의미.
# 원본 이미지에 보이는 문자 수 + '*' 개수 = 전체 문자열 길이가 반드시 같아야 함.
# '*' 개수를 임의로 늘리거나 줄이지 말 것.

[coordinate]
# 이미지 내의 각 세그먼트들(영수증, 여권)의 정보를 기록한다.
# 좌표 스케일 : pixel
# 원점 : top-left
# x → right, y → down
# {top : 0, bottom : 0, left : 0, right : 0}의 형태로 기록한다.

[hash_img]
# 유저 프롬프트 최상단에 제공 (반드시 입력받은 해시 값을 그대로 적어서 반환할 것.)

[유의점]
# 여권
    - 여권 정보 판독이 어려우면 기계판독 영역도 참고할 수 있다.
# 영수증 공통
    - <면세점 이름>은 "LOTTE", "SILLA", "HYUNDAI", "SHINSEGAE" 로 나눈다. 그 외는 "etc." 로 표기.
    - [LOTTE]
        - 영수증 구매자 이름 표기 : 
            앞 1자, 뒤 1자 외 모두 *로 마스킹
        - 국가코드 & 영수증 여권 번호 표기 : <국가코드(3자리)>-<여권번호(9자리)> 
          ※앞 4자리 외 모두 *로 마스킹
          ※예시 : RUS-AK79***** (국가번호 : RUS, 여권번호 : AK79*****)

[금지 사항]
# 실제 존재할 법한 값으로 임의로 바꾸지 말 것.

[반환 규칙]
# 모든 JSON은 한 줄로 출력한다 (개행, 들여쓰기 금지).
# 영수증 / 여권이 아닌 경우에도 형식을 유지한다. (각 카운트가 0, 리스트 내부를 빈 리스트로)
# 반드시 RFC8259 유효 JSON만 반환한다.
# 모든 key는 반드시 double quote(")로 감싼다.
# 문자열은 반드시 double quote(")로 감싼다.
# trailing comma 금지, 주석/설명 문장/마크다운 코드블록 금지.
# 최종 응답은 JSON 객체 하나만 반환한다.
# 반환 JSON의 key는 아래 [반환 형식]에 명시된 key만 사용하고, 철자/대소문자를 절대 변경하지 말 것.
