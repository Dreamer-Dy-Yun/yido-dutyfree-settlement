# Upload Components

Data-mapping upload UI components live here.

| File | Responsibility |
| --- | --- |
| `FileUploadPanel.jsx` | Shared drag/drop, file selection, upload state, and result rendering for data-mapping uploads. |
| `FileUploadPanel.css` | Upload panel, dropzone, selected-file, and upload control styles. |

Feature wrappers such as `EdiUploadPanel.jsx` and `ImageZipUploadPanel.jsx` provide copy, accepted file types, extra controls, and API functions.
