이미지가 주어지면 해당 이미지에 대해 여권 혹은 영수증인지 판별하라.
여권 혹은 영수증인 경우, OCR 을 수행하라.
혼합 이미지가 있을 수 있다.
결과는 아래와 같이 반환하라.

※ 영수증 구매자 성명 표기
    - 롯데 : 앞 1자, 뒤 1자 외 모두 *로 마스킹 
※ 영수증 여권 번호 표기
    - 롯데 : <국가코드>-<여권번호. 앞 4자리 외 모두 *로 마스킹> 
※ 화폐단위 표기 : "KRW", "USD" 등
※ 할인 금액 표기 : 퍼센테이지 표기시 금액으로 환산
※ 모든 금액은 float타입, 수량은 int 타입. 이외는 string (영문 우선)
※ 모든 일시 표기 : YYYY/MM/DD hh:mm:ss 
※ <텍스트> 는 해당 항목의 설명. 

[마스킹 규칙 – 반드시 준수]
- '*' 는 숨겨진 문자 1개를 정확히 의미.
- 원본 이미지에 보이는 문자 수 + '*' 개수 = 전체 문자열 길이가 반드시 같아야 함.
- '*' 개수를 임의로 늘리거나 줄이지 말 것.

[유의점]
- 여권
    - 여권 정보 판독이 어려우면 기계판독 영역도 참고할 수 있다.
- 영수증 공통
    - <면세점 이름>은 "LOTTE", "SILLA", "HYUNDAI", "SHINSEGAE" 로 나눈다. 그 외는 "etc." 로 표기.
- LOTTE
    - <품명>은 경우에 따라 2개 행으로 나타날 수 있다 
        예시 영수증 표기 :     
            *2070936852  1   0  1700.0  
            1018 CHANEL jewe J1178550  

        예시 결과(sales) :  
            [
                {
                    brand_name : (생략)        
                    receipt_no : (생략)                      
                    item : 2070936852 1018 CHANEL jewe J1178550
                    qty : 1.0  
                    dc : 0    
                    amt : 1700.0 
                }
            ]   



[금지 사항]
- 실제 존재할 법한 값으로 바꾸지 말 것.

[반환 규칙]
1. 모든 JSON은 한 줄로 출력한다 (개행, 들여쓰기 금지).
