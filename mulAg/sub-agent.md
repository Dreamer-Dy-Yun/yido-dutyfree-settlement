# sub-agent.md

## todo 참조 규칙
- Sub-Agent는 할당된 `todo/*.md`만 작업 기준으로 삼는다.
- todo에 명시되지 않은 plan 문서는 기준으로만 참고하고 직접 수정하지 않는다.
- 참조 plan/todo는 review 최상단에 반드시 기재한다.

## 작업 수행 규칙
- todo의 `작업 범위`와 `완료 기준`만 수행한다.
- todo에 누락된 경로/문맥이 필요하면 즉시 수정하지 않고 review의 이슈로 남긴다.
- `todo`에서 지정한 선행 조건이 충족된 경우에만 진행.
- 임시 해결 대신 계약 준수와 방어적 처리로 대응한다.

## 파일 수정 제한
- todo의 `수정 가능 파일`만 편집 가능.
- `수정 금지 파일`은 읽기/수정/삭제 모두 금지.
- 동일 파일 병렬 수정 금지; 기존 변경이 있는 경우 책임자와 범위를 재조정한다.

## 생성 가능 파일 제한
- todo의 `생성 가능 파일`만 생성한다.
- 생성 파일은 변경 목적에 필요한 최소 집합으로 제한한다.
- 목적과 무관한 보조 문서 생성은 금지.

## 작업 범위 이탈 시 처리 방식
- 범위 이탈 필요사항 발견 시 바로 작업 중단 후 review에:
  - 이탈 사유
  - 대상 파일
  - 영향 범위
  - 요청 수정안
  을 남긴다.

## review 작성 규칙
- 형식:
```markdown
# REVIEW: 작업명
## 수행 일시
## 참조 plan
## 참조한 todo
## 수행 내용
## 변경 파일
## 생성 파일
## 미변경 파일
## 검증 내용
## 남은 이슈
## QA 확인 요청 사항
```
- 수행 일시는 `YYYY-MM-DD HH:mm:ss` 형식.
- 완료 기준 미달 항목은 "남은 이슈"에 구체적으로 작성.
