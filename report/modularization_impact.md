1. 각 모듈의 기능이 사용되는 파일마다 중복 구현되었다고 가정
2. 각 구현마다 동일한 수준의 테스트가 필요하다고 가정

### 모듈화의 가치
- **유지보수성**: 한 곳만 수정하면 모든 사용처에 반영
- **테스트 효율성**: 한 번만 테스트하면 모든 사용처에서 신뢰 가능
- **버그 예방**: 중복 구현 시 발생할 수 있는 버그 방지
- **개발 속도**: 재사용 가능한 모듈로 빠른 개발

## 추가 고려사항

### 실제로는 더 많을 수 있는 이유
1. **각 파일마다 구현 방식이 다를 수 있음** → 각각 다른 테스트 필요
2. **통합 테스트도 중복 필요** → 각 파일별 통합 테스트 추가
3. **버그 수정 시 모든 파일 수정** → 각 파일별 회귀 테스트 필요

### 보수적 추정
- 실제로는 **4,000~5,000개** 이상의 테스트가 필요했을 가능성 높음
